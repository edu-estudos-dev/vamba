# MVP

O MVP deve ser pequeno e responder se turistas abrem o Vamba repetidamente enquanto estão viajando.

## Entra no MVP

1. Localização.
2. Descoberta de lugares reais.
3. Recomendação inteligente.
4. Detalhes.
5. Rota externa.
6. Tradutor.
7. Favoritos.
8. Analytics básicos.
9. Integração inicial com pelo menos um afiliado quando possível.

## Não entra agora

- Rede social.
- Chat entre turistas.
- Marketplace próprio.
- Sistema próprio de reviews.
- Checkout próprio.
- Hotel, passagem ou navegação próprios.
- Realidade aumentada.
- Áudio-guia completo.
- Tradução simultânea avançada.
- Sistema de publicidade.
- Microservices.
- Kubernetes.
- Redis sem necessidade demonstrada.
- Stripe.
- Formalização de empresa.

## Milestone 0

Criar a base técnica e documental executável, sem credenciais e sem integrações pagas.

## Milestone 1

Vertical slice:

```text
GPS -> lugares reais -> IA -> recomendação -> detalhes -> rota externa
```
